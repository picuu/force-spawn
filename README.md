# ForceSpawn Minecraft plugin

Force players to spawn on a specific location when they join the server.

> Soon: Will add the possibility to configure also a forced spawn point for when players respawn

> [!NOTE]
> This project is in very early development phase.

This is a PaperMC plugin for Minecraft 26.3 (Java 25).
